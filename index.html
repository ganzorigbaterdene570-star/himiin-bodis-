Token хаанаас авах вэ?

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → "Generate new token". Repository access: Only select repositories → himiin-bodis-. Permissions: Contents → Read and write. Бусад бүх зөвшөөрлийг хоосон орхино. Token зөвхөн энэ компьютерийн browser дээр (localStorage) хадгалагдана, надад ч, серверт ч илгээгдэхгүй.
