# Химийн бодисын хяналтын самбар

Мак Аранжин Зэс ХХК-ийн хүхрийн хүчлийн орлого/зарлагын хяналтын самбар.
Өгөгдөл `data.json` файлд хадгалагдана, GitHub Pages дээр статик вэб хуудас
болгон харуулагдана.

## Хэрхэн ажилладаг вэ

- **Харах**: хэн ч линкээр орж, хяналтын самбарыг харж болно (нэвтрэх шаардлагагүй).
- **Мөр нэмэх**: хуудасны доод хэсэгт байгаа "⚙ Админ горим" товч дарж, GitHub
  Personal Access Token-оо оруулснаар шинэ гүйлгээ нэмэх боломжтой. Token нь
  зөвхөн таны browser дээр (localStorage) хадгалагдана.

## GitHub Pages асаах

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / `(root)` → Save.
